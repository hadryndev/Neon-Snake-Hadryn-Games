# Neon Snake — v1.3.0 🐍

A browser-based arcade Snake game by **Hadryn Games**, built using HTML5, CSS3 and vanilla JavaScript.

**Play online:** https://hadryndev.github.io/Neon-Snake-Hadryn-Games/

## What's new in v1.3.0

- **Two moving Glowing Barriers** on fixed horizontal patrol routes.
- **Barrier Breaker:** block a barrier in its current direction for **3 consecutive seconds** to destroy it. Each barrier is independent.
- **Fake Food** may bring a destroyed barrier back, with a warning before it respawns.
- **Achievements**, including Barrier Breaker and The Perfect Snake.
- **3, 2, 1, SURVIVE!!!** countdown with animated fade transitions and no buffered direction inputs.
- **Grid Guide:** optional subtle row/column guides for collectible items.
- **More responsive controls:** a short directional input queue for rapid turns.
- **Smooth, continuous snake body** with rounded corners; the original head style remains.
- **Balance:** normal speed **6.5 cells/s** and Speed Boost **8.5 cells/s**. During Boost, Food gives double score and double growth.
- The existing Shrink and high-score features remain.

## Controls

- **Move:** Arrow keys or WASD
- **Pause:** Space or the Pause button
- **Restart:** Restart button
- **Touch:** Swipe on the board or use the directional buttons

## Run locally

Open `index.html` in a modern browser. No build tools or dependencies required.
