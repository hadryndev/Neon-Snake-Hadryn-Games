# Neon Snake 🐍

Snake moderno feito em **HTML, CSS e JavaScript puro**, sem dependências e sem etapa de compilação. Projeto da Hadryn Games.

## Como jogar

Abra `index.html` em qualquer navegador moderno. Use **setas ou WASD**, **Espaço** para pausar, ou os botões/toques na tela do celular.

## Recursos

- Layout responsivo com visual neon
- Pontuação, níveis de velocidade e recorde salvo no navegador (`localStorage`)
- Controles de teclado, botões e gestos
- Pausa e reinício
- Funciona offline

## Publicação com GitHub Pages

1. Crie um repositório **público** chamado `neon-snake` no GitHub.
2. Envie os arquivos `index.html` e `README.md` na raiz da branch `main`.
3. Acesse **Settings > Pages > Build and deployment**, escolha **Deploy from a branch**, branch **main** e pasta **/(root)**. Salve.
4. Aguarde a publicação. O endereço normalmente será `https://SEU-USUARIO.github.io/neon-snake/`.
